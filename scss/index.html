Scss tutorial

scss is a tool for compiling styles written in a new format into regular css file which is well known for browsers. it has some features like variables and functions. with compiling these file you can view simple css codes.

installation: npm install -g sass
compiling: sass input.scss output.css
if you have vscode installed on your machine you can use extension named "live sass compiler"

features

variables

you can define variables just like this: 

        $primary-color: #225522;


        .some-classes {
            color: $primary-color;
        }
sass compiles upper code into following: 

        .some-classes {
            color: #225522;
        }

note that we already have variables supported in plain css files. but it is supported in latest version of browser. by doing this you can support more browsers.

maps

scss have feature that you can define maps and use them. example: 


        $font-weights: (
            "regular": 400,
            "bold": 600,
            "bolder": 800
        );

        p {
            font-weight: map-get($font-weights, bolder)
        }

it is compiled to following code:


        p {
            font-weight: 800;
        }
